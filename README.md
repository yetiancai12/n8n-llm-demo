# n8n + LLM demo: client requirement → summary + quote draft
Flow: Webhook (POST /webhook/quote-draft) → Build Prompt (Code) → Call LLM (HTTP, OpenAI-compatible) → Parse Quote (Code, clamps price to $350–1200, status always `draft`) → Respond.

## Files
- `workflow.json` – import in n8n (Workflows → Import from file). Generated by `node build.js` from `nodes/*.js`.
- `sample-input.json` / `sample-output.json` – example request and draft response.
- `simulate.js` – local test with a mock LLM server; runs the real Code-node sources. `node simulate.js`

## Setup
1. Import workflow.json.
2. Replace `{{PLACEHOLDER_LLM_API_KEY}}` in the Call LLM node header with your key (better: use an n8n Header Auth credential). Optional env `LLM_BASE_URL` for other OpenAI-compatible providers.
3. Activate, then: `curl -X POST <n8n-url>/webhook/quote-draft -H 'Content-Type: application/json' -d @sample-input.json`
